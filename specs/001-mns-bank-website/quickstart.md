# Quickstart: MNS Bank Website

This guide explains how to set up the MNS Bank website for local development.

## Prerequisites
- Node.js 20.x or later (Next.js 16 requires Node 18.17+, 20.x recommended)
- `npm` 10.x or later
- Git

## 1. Initial Setup
1. Clone the repository and checkout the feature branch:
```bash
git checkout 001-mns-bank-website
```
2. Install dependencies:
```bash
npm install
```

## 2. Environment Variables
Copy the example environment file and fill in required values.
```bash
cp .env.example .env.local
```
**Required Variables in `.env.local`**:
- `NEXT_PUBLIC_RECAPTCHA_SITE_KEY` - The reCAPTCHA v3 site key for `mnsbankbhopal.com` (use test keys for local dev).
- `RECAPTCHA_SECRET_KEY` - The reCAPTCHA v3 secret key.
- `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS` - Credentials for the email dispatch service.
- `ADMIN_PASSWORD` - The password to access the built-in CMS admin routes.

## 3. Running the Development Server
Start the Next.js development server:
```bash
npm run dev
```
The site will be available at `http://localhost:3000`.

### Important Next.js 16 Notes
- **Instant Navigation**: The Next.js dev tools will show an "Instant Nav" option. You can use this to visually debug the static shells generated by `unstable_instant`.
- **Caching**: The App Router aggressively caches data. If you make changes to CMS JSON files locally while the dev server is running, they should hot reload, but API route responses might be cached depending on the segment configs.

## 4. Testing
Run the unit test suite (Jest):
```bash
npm run test
```

Run the end-to-end tests (Playwright):
```bash
npm run test:e2e
```

## 5. Mock Data (CMS)
The built-in CMS stores data in `src/data/`. By default, this directory contains empty arrays or placeholder files. You can copy the examples from `src/data/examples/` to populate your local environment with dummy Rates, News, and DEAF records.
